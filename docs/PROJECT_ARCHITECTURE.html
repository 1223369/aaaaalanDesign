启动链路:
index.html
  -> src/main.ts
  -> createApp(App)
  -> app.use(core)
  -> router-view 渲染 /editor
  -> EditorMain.startup()
  -> initServices()
  -> 创建 MLeaferCanvas
  -> canvasEdit.vue append(canvas.wrapperEl)

添加文字链路:
TextListWrap.vue 点击
  -> new Text / new HTMLText
  -> editor.add(text)
  -> contentFrame.add(text)
  -> selectObject(text)
  -> childrenEffect()
  -> 图层面板和属性面板更新

切换页面链路:
WorkspacesService.setCurrentId
  -> workspaceChangeBefore
  -> 保存旧页面 contentFrame.toJSON()
  -> workspaceChangeAfter
  -> importJsonToCurrentPage(newPage)
  -> zoomToFit()
